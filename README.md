# instructions
Firstly, open ```robloxUSR.txt``` file and type in your name, **NOT DISPLAY NAME!**
then, run in the terminal inside the folder "```cmd python -m pip install -r requirements.txt```"
lastly, open ```avatar to ai image.exe``` file to get the avatar into a file in the folder

# aftermath
after a while, a microsoft edge window will open, opening **copilot**.
the image of your avatar was automatically copied to the clipboard, so all you need to do is paste in the chat (that was customized to turn your avatar into an image).

you can also (before sending the image) use the ```tagger.exe``` file to create tags.. the tags gets copied to the clipboard so you can paste them after pasting the image.
press enter and wait for the ai to finish generating.
